# Этап 3 — Генератор синтетики

- **Дата:** 2026-09-14
- **Статус:** завершён
- **Где выполнялось:** локальная машина **без GPU**, код реально запускался
- **Окружение:** Python 3.10.12, Pillow, OpenCV, cairosvg 2.9.1

## 1. Цель этапа

Закрыть дефицит реальных type1a / type1b из Этапа 2 процедурной генерацией
≥ 5000 изображений с геометрией ГОСТ Р 50577-2018, перспективной постановкой
на сцену и аугментациями `conditions`, с воспроизводимостью по `--seed`.

## 2. Что реализовано

### 2.1 Рендер пластины (`dataset/generator/plate_render.py`)

| Тип | Основа |
|-----|--------|
| **type1** | [maerty1/Russia-number-plate-generator](https://github.com/maerty1/Russia-number-plate-generator): SVG-бланк + RoadNumbers 2.0, `FONT_SIZE=135`, слоты 58/174/76/58, регион 95; кегль региона ограничен размером 3-значного кода (иначе 2 цифры остаются 135 и перекрывают RUS) |
| **type1b** | тот же рисунок type1, перекраска нейтрального поля в жёлтый (флаг сохраняется); бланк Aquagen `MM00055` **не** используется |
| **type1a** | бланк `assets/type1a_blank.png` (рамка региона + RUS/флаг); символы проставляются поверх, буквы и цифры с раздельным кеглем |
| **other** | type1-раскладка красным цветом (дипломатический/чужой вид) |

### 2.2 Сцена и аугментации (`scene.py` + `generate.py`)

- Фон: асфальт + упрощённый бампер, день/ночь.
- Перспективный warp пластины в случайный quad.
- Фотометрия: rain / snow / dirt / glare / motion_blur / angle (пишется в `conditions`).
- Разметка: строка в `meta.csv` (`is_synthetic=1`) + YOLO-label в `labels/`.

### 2.3 CLI

```bash
python scripts/build_synthetic.py --count 5000 --seed 42
```

Микс по умолчанию (закрытие дефицита Этапа 2):

`type1=0.22, type1a=0.38, type1b=0.32, other=0.08`

## 7. Ограничения

- Локально нет GPU; обучение детектора/OCR — Этапы 4–5 на GPU-сервере.
