# Проверка перед публикацией — 30.09.2026

Проверены ТЗ полуфинала, точки входа, поставка весов, формат CSV и текущий
локальный датасет. Дообучение не проводилось.

## Исправления

- CSV использует имя файла без пути. При совпадающих именах во вложенных
  каталогах CLI сообщает об неоднозначности вместо смешивания результатов.
- Для пустого входного каталога записывается CSV с заголовком.
- Основной runtime не выдаёт маски вне ТЗ как целевые типы: такие знаки
  относятся к `other`. Уверенность ограничена конечными числами от 0 до 1.
- Бенчмарк измеряет тот же движок, что и инференс. Режим `--latency-only`
  не требует meta.csv или GT-разметки.
- Валидатор проверяет наличие меток, читаемость изображений, положительные
  размеры bbox, границы изображений и невырожденность quad.
  Объём синтетики считается по изображениям, а не по строкам.
- Из локальной резервной копии восстановлены 754 изображения и 754 метки
  с точным совпадением относительных путей. meta.csv не переписывался.
- Добавлено отдельное окружение для запуска без зависимостей сбора данных
  и PaddlePaddle; активные ONNX-веса включены в поставку.

## Проверка требований

Код поддерживает каталог изображений, несколько знаков на кадре,
CSV UTF-8 с разделителем `;`, маску и символ `#`, локальные веса,
синтетический генератор с seed и запуск на CPU/CUDA.

Локальный валидатор: PASS, 0 ошибок; 6132 строки, 5904 изображения,
982 реальных объекта и 5150 синтетических.
Он не заменяет обязательную проверку валидатором организаторов.

Личный размеченный датасет пользователя в Roboflow не исследован:
ссылка и версия не предоставлены. Локальный набор содержит 0 реальных type1a,
19 изображений type1b и 2 изображения other. Эти числа не описывают личный
датасет пользователя. Нужен его экспорт с текстом номера и происхождением,
чтобы подтвердить комплектность итоговой сдачи; обучение для этого не требуется.

Исторический Kaggle-замер исходного pose+CRNN: 200.01 мс/изображение на CPU,
end-to-end exact 56.52% на 1219 читаемых объектах. Это результат исходного
runtime без дополнительного контекстного фильтра текущего адаптера,
до настоящих исправлений. Это не повторная оценка опубликованной версии
и не замер на GTX 1050 Ti. Бюджет 100 мс на референсном ПК остаётся неподтверждённым.

Скрипт train_detector.py обучает bbox-детектор. Обучение выбранных сторонних
pose/CRNN-весов в проекте не воспроизводится; train_ocr.py явно сообщает,
что обучение не реализовано. Это ограничение относительно требования ТЗ
передать скрипты обучения всех моделей.

Пояснительная записка предоставлена в Markdown. Лимит пяти страниц
следует проверить после финального оформления документа.
