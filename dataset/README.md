# Датасет GRZ Recognition

Данные для детекции и распознавания российских номерных знаков
`type1`, `type1a`, `type1b` и негативного класса `other`.

## Структура

```text
dataset/
  images/real/             реальные фотографии
  images/synthetic/        синтетические изображения
  images/synthetic_style_b/ дополнительный синтетический стиль
  labels/                  YOLO bbox-разметка, файл на изображение
  meta.csv                 метаданные, строка на знак
  generator/               генератор и его ресурсы
  README.md
  LICENSE
  validation_report.txt
```

`meta.csv` использует UTF-8 и разделитель `;`. Поля:
`image;plate_num;plate_type;bbox;quad;is_vehicle;is_synthetic;source;license;conditions`.

Пути `image` заданы относительно `dataset/`. `bbox` имеет формат `x,y,w,h`
в пикселях. `quad` — четыре точки по часовой стрелке от левого верхнего угла.
Номера записываются заглавными латинскими буквами; нечитаемые позиции — `#`.

## Источники и методика

Собственный размеченный набор реальных фотографий с ГРЗ доступен в
[проекте Roboflow sergai / 1-djo2q](https://app.roboflow.com/sergai/1-djo2q/models).
Он предназначен для детекции и классификации номерных знаков.
Приведённая ниже статистика относится к локальному архиву датасета.


Реальная часть локального набора получена из
[tatmantech/russian-license-plates-ec7zg, версия 2](https://universe.roboflow.com/tatmantech/russian-license-plates-ec7zg)
через официальный экспорт Roboflow. В реестре источника записана CC BY 4.0;
происхождение каждого объекта указано в `source` и `license`.

Рамки взяты из разметки источника. Углы для bbox-разметки соответствуют углам
прямоугольника, а не вручную измеренной перспективе. Тип уточняется по метаданным,
цвету и геометрии. Текст используется из имени исходного файла только для
изображений с одним знаком и после проверки маски. Для остальных объектов
сохранены неизвестные позиции. Автоматическая разметка не объявляется ручной.

Фильтры сбора включают проверку лицензии, качества, perceptual-hash
дедупликацию и размытие обнаруженных лиц. Изображения отладочного набора
организаторов исключаются при сборе через параметр `--debug-set`.

Синтетическая часть создана собственным генератором: шаблоны знаков,
перспективные преобразования, фон, освещение и искажения. Дополнительный
стиль `synthetic_style_b` предназначен для проверки переноса между стилями.
Атрибуция ресурсов приведена в `generator/assets/README.md` и `generator/fonts/LICENSE`.

## Состав локального набора

Актуальная проверка от 30.09.2026: **6132 объекта, 5904 изображения**.
Реальная часть: 982 объекта на 754 изображениях.
Синтетическая часть: 5150 объектов на 5150 изображениях.

По типам: `type1` — 2087 объектов; `type1a` — 2072;
`type1b` — 1573; `other` — 400.
Полная статистика по происхождению и читаемым номерам содержится
в `validation_report.txt`.

## Воспроизведение и проверка

Из корня репозитория:

```bash
pip install -r requirements-dev.txt
python scripts/build_synthetic.py --out dataset --count 5000 --seed 42
python scripts/validate_dataset.py --dataset dataset
```

Генератор фиксирует random seed. `synthetic_style_b` создаётся отдельно
скриптом подготовки выборок. Отчёт `validation_report.txt` создан локальным
валидатором проекта; валидатор организаторов запускается отдельно, когда доступен.

## Лицензия

Датасет распространяется по CC BY 4.0, полный текст — в `LICENSE`.
Атрибуция реальных материалов сохраняется в `meta.csv`.
Фотографии и файлы разметки передаются в отдельном архиве датасета;
код генератора и метаданные находятся в Git-репозитории.
